TECHNOVERSE V5.3 — Knowledge Paths + Interactive Science Labs

项目文件：
- index.html：页面布局、搜索面板、路径规划和详情面板
- main.js：Three.js 场景、科技节点、关系线、搜索、镜头飞行、最短关联路径
- technologies.js：127 个科技节点及其知识网络 links
- experiments.js：DNA、光学、电路、力学、神经网络图形实验
- style.css：界面和响应式样式
- ROADMAP.txt：下一阶段计划

本次合并更新（V5.2 + V5.3）：
1. 知识路径规划：可分别选择任意两个节点，按数据库 links 作为无向关系网使用 BFS 搜索最短路径，并高亮路径上的节点和连线；镜头飞向路径中段。
2. 关联科技说明：节点详情列出最多 10 个直接关联节点，标示同学科/跨学科，点击可飞向该节点。
3. 关系解释保持谨慎：连线代表项目数据库中收录的关联，不自动宣称直接因果关系。
4. DNA 实验：双链可视化、解旋、半保留复制示意；增加碱基替换/插入/缺失模拟，互补链按 A-T、C-G 规则更新。
5. 光学实验：支持凸透镜/凹透镜切换，调整物距和焦距；显示像距、像的正倒、虚实、大小趋势，并绘出主光线示意。
6. 保留 127 个节点、黄金角布局、节点生成动画、搜索与相机飞行，以及电路/力学/神经网络实验。
7. 按要求不加入传统时间轴。

运行方式：
- 将所有文件放在同一文件夹。
- 推荐 VS Code + Live Server 启动 index.html；不要直接用 file:// 打开 ES module 项目。
- 需要网络连接加载 Three.js CDN。
- 更新旧版前先备份；首次打开按 Ctrl+F5 强制刷新。

模型边界：
- 路径是按当前 links 数据计算出的图最短路径，不代表唯一的历史因果链。
- DNA 是教学示意模型，不用于预测实际遗传性状。
- 光学图为教学示意，像距很大或超出视口时会标记截断；模型使用薄透镜公式。
